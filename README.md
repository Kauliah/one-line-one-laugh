One funny line of text, short enough to read in a breath and whole enough to land on its own — an entry for make.fun's "One Line, One Laugh" bounty. The program validates the line (1–140 characters, a single line, no control characters) and writes it to `/output/entry.txt`, then reads it back and fails if the bytes differ.

The line:

> I hired a life coach; he took one look at my browser tabs and referred me to an exorcist.

## Run it

```sh
npx tsx main.ts
```

or, with plain Node 22+ (type stripping):

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere other than `/output`.
